# Digital – UI/UX Design Agency Landing Page

Digital is a modern, responsive landing page for a fictional UI/UX design agency. It presents the agency through a bold hero section with a headline, a short pitch, a "Learn More" call-to-action button, and social media links, all in a clean layout that adapts to desktop, tablet, and mobile screens.

The page includes a collapsible mobile navigation menu and smooth scroll-reveal animations, so the hero content appears one element after another. It is built with HTML, CSS, and vanilla JavaScript, using ScrollReveal for animations and Remixicon for icons.
